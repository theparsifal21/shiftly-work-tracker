# SHIFTLY

Personal work schedule and salary tracker.

[Open SHIFTLY](https://theparsifal21.github.io/shiftly-work-tracker/)

## Features
- Monthly shift calendar and editable shifts.
- Schedule screenshot import and OCR workflow.
- Salary estimates in HUF and configurable work rules.
- Local browser storage.

Verify imported shifts and salary estimates manually. Export or retain backups where supported.
